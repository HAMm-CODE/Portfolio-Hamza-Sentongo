A Python ETL project that extracts top bank market-cap data from a public webpage, transforms the values into multiple currencies, and loads the results into CSV and SQLite.

## What I built

- Extracted tabular data from a public webpage.
- Cleaned and transformed market-cap values using Python and Pandas.
- Applied exchange-rate conversion into GBP, EUR, and INR.
- Loaded the final dataset into a CSV file and SQLite database.

## Why this matters

This project shows the basic structure of a complete ETL workflow: extract, transform, validate, and load. It is a good foundation project for junior data engineering roles.

## Tech stack

Python, Pandas, BeautifulSoup, SQLite, CSV.
