A Databricks-style PySpark project combining static data analysis, structured streaming concepts, and machine learning.

## What I built

- Loaded and processed retail sales data with PySpark.
- Built batch-style transformations for sales analysis.
- Explored structured streaming workflows.
- Trained and evaluated a linear regression model.
- Applied the model to analyze sales-related patterns.

## Why this matters

This project connects core data engineering work with machine learning workflows. It shows the ability to process data at scale, prepare features, and understand how analytical models fit into a data pipeline.

## Tech stack

PySpark, Spark Structured Streaming, Spark ML, Databricks-style notebooks.
