# Hamza HugoBlox Portfolio Starter Pack

This pack contains starter content for the HugoBlox Academic CV template:
https://github.com/HugoBlox/hugo-theme-academic-cv

## How to use

1. Create a new HugoBlox Academic CV site:

```bash
npx hugoblox create site --template academic-cv
```

2. Copy the folders in this starter pack into your new site folder:

```text
data/authors/me.yaml
content/_index.md
content/projects/*
content/blog/portfolio-notes/index.md
config/_default/menus.yaml
config/_default/params.yaml
```

3. Add your files:

```text
assets/media/avatar.jpg        # your profile photo
static/uploads/resume.pdf      # your latest CV PDF
```

4. Preview locally:

```bash
hugo server
```

5. Deploy with GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
