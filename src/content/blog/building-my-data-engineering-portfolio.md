A strong data engineering portfolio should not only list tools. It should show how those tools are used to move data from raw input to reliable output.

My current focus is on projects that demonstrate practical data engineering skills:

- building ETL/ELT pipelines,
- processing data with PySpark,
- comparing data lake formats such as CSV, Parquet, and Delta Lake,
- loading transformed data into databases,
- documenting decisions clearly.

The goal is to make each project easy for a recruiter or hiring manager to understand quickly: what problem it solves, what technologies were used, and what data engineering skill it proves.
