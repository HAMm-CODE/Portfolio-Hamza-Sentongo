## Overview

This is a small but complete ETL pipeline. It extracts the top banks by market capitalization from a public webpage, transforms the values into multiple currencies using exchange-rate data, and loads the final dataset into both a CSV file and an SQLite database.

## What I built

- Extracted bank market-cap data from a public webpage.
- Cleaned and transformed the data with Python.
- Converted market-cap values into GBP, EUR, and INR.
- Loaded the final dataset into CSV and SQLite.
- Wrote the pipeline as a repeatable Python workflow.

## Tech stack

**Python · Pandas · BeautifulSoup · Requests · SQLite · CSV · ETL**

## What this project demonstrates

- End-to-end ETL structure.
- Web data extraction.
- Data cleaning and transformation.
- Loading data into both file and database outputs.
- Clear pipeline thinking for small data engineering tasks.
