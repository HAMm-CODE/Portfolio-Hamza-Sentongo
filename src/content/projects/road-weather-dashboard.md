## Overview

This project explores real-time road weather data and visualizes selected station measurements in a web dashboard. It combines backend API integration with frontend charts.

## What I built

- Built a Spring Boot backend for fetching road weather station data.
- Processed road friction, road surface temperature, and condition data.
- Built a React frontend with chart-based visualizations.
- Displayed station-based measurements over a 24-hour period.

## Tech stack

**Java · Spring Boot · React · Recharts · REST APIs · Data Visualization**

## What this project demonstrates

- API integration and backend service design.
- Handling external data sources.
- Frontend visualization of time-based measurements.
- Combining software engineering with data-focused applications.
