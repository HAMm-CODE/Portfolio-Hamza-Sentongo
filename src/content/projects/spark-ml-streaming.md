## Overview

This project combines **Spark Structured Streaming** concepts with a simple machine learning workflow in PySpark. The project uses retail-style data to explore how static and streaming-style datasets can be processed and analyzed in Spark.

## What I built

- Created a Databricks-style PySpark notebook.
- Processed static retail sales data.
- Simulated or handled streaming-style input data.
- Trained and evaluated a linear regression model.
- Applied the trained model to analyze sales-related patterns.

## Tech stack

**PySpark · Spark Structured Streaming · Spark ML · Databricks-style notebooks**

## What this project demonstrates

- Batch and streaming data processing concepts.
- ML workflow integration inside Spark.
- Data transformation and analysis using PySpark.
- Ability to work with notebook-based data engineering workflows.
